# قاعدة التزامن التلقائي مع GitHub

بناءً على توجيه المستخدم الدائم:
- مع كل تحديث أو تعديل أو إضافة أي ميزة جديدة في المنصة، يجب دائماً تنفيذ خطوات Git التالية تلقائياً:
  1. فحص التعديلات وتجهيزها: `git add .`
  2. إنشاء Commit بوصف دقيق ومحدد لما تم إنجازه.
  3. رفع التحديثات إلى المستودع البعيد: `git push origin main`
- في حال وجود انقطاع مؤقت في الاتصال بالشبكة، يتم حفظ الـ Commit محلياً وإبلاغ المستخدم لإعادة الرفع فور عودة الاتصال.
