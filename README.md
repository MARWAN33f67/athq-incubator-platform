# منصة حاضنة ومسرعة عذق - جمعية البر بالمدينة المنورة
## وثيقة المشروع والنظام التجريبي المتكامل (Full-Stack MVP)

مبادرة تنموية رائدة أطلقتها **جمعية البر بالمدينة المنورة** (تأسست عام 1379هـ - مسجلة برقم 22) برئاسة كريمة من **صاحب السمو الملكي الأمير سلمان بن سلطان بن عبدالعزيز أمير منطقة المدينة المنورة**، بالشراكة الاستراتيجية مع **المركز الوطني لتنمية القطاع غير الربحي** وتشغيل **شركة المتقن (ALMUTQEN)**.

### 🗺️ أولاً: تحليل ومطابقة خرائط سير العمل (BPMN Workflow Integration)

تمت مطابقة خرائط BPMN الأربع المرفقة وتحويلها إلى واجهات وأنظمة تفاعلية حية متصلة بالباك اند:

| المرحلة في BPMN | الفئة المستهدفة | الوظائف المنفذة في المنصة |
|---|---|---|
| **المرحلة 1** | **الزائر العام** | • تصفح الواجهة الرئيسية ورؤية الحاضنة.<br>• استعراض المرافق (قاعات، مقرات، مساحات مشتركة).<br>• استعراض مسارات الدعم الخمسة وكتيب البرامج.<br>• لوحة الإحصائيات والأرقام المعتمدة.<br>• الأسئلة الشائعة وشروط الانضمام.<br>• المساعد الذكي الفوري (مساعد عذق).<br>• زرا الدعوة لاتخاذ إجراء (تسجيل جمعية / انضم كمستشار). |
| **المرحلة 2** | **الجمعية المحتضنة** | • نموذج تسجيل وانضمام متكامل مع تدقيق البيانات.<br>• مؤشر تقدم المراحل الأربع للاحتضان (الفكرة -> التهيئة -> الاحتضان المكاني -> مسرعة عذق).<br>• مستودع رفع الشواهد ووثائق الحوكمة واعتمادها.<br>• حجز المرافق والقاعات والمقرات.<br>• طلب وحجز الجلسات الاستشارية مع الخبراء. |
| **المرحلة 3** | **بوابة المستشار** | • تسجيل واعتماد حساب المستشار وتحديد التخصص وسنوات الخبرة.<br>• جدول أوقات التفرغ وساعات العمل المتاحة.<br>• استعراض ملف الجمعية واحتياجها قبل الجلسة.<br>• عقد الجلسة (حضوري بالحاضنة أو افتراضي).<br>• كتابة تقرير الجلسة والتوصيات وحفظها.<br>• الاحتساب التلقائي للساعات الاستشارية والتطوعية في رصيد المستشار وإحصائيات الحاضنة. |
| **المرحلة 4** | **لوحة الإدارة (Admin)** | • مراجعة وفحص طلبات الاحتضان الجديدة.<br>• اتخاذ قرار القبول/الرفض مع كتابة التوجيهات وإرسال الإشعارات.<br>• ترقية مراحل الاحتضان للجمعيات.<br>• اعتماد وجدولة حجوزات المرافق ومساحات العمل.<br>• توليد وتصدير التقارير التنفيذية ومؤشرات الأداء (KPIs). |

### 💻 ثالثاً: معمارية النظام البرمجية (Full-Stack Architecture)

- **Frontend**:
  - `public/index.html`: هيكل دلالي متوافق مع معايير الويب الحديثة، ثنائي النمط (داكن/فاتح)، يدعم العربية من اليمين لليسار (RTL).
  - `public/css/style.css`: نظام تصميم أنيق بألوان الهوية الرسمية (الأخضر العذقي الملكي والذهبي)، وتأثيرات زجاجية راقية (Glassmorphism).
  - `public/js/app.js`: منطق التفاعل، إدارة حالة النظام، والاتصال بالـ API.
  - `public/js/data.js`: البيانات الأولية المطابقة للكتيبات.
- **Backend**:
  - `server.ps1`: خادم REST API أصلي سريع لا يحتاج لتثبيت أي برامج خارجية ويعمل مباشرة عبر PowerShell.
  - `data/db.json`: قاعدة بيانات محلية JSON تحفظ التعديلات والحجوزات والطلبات وتسترجعها باستمرار.
- **Launchers**:
  - `start-server.bat`: ملف تشغيل بنقرة واحدة يقوم ببدء السيرفر وفتح المتصفح تلقائياً على `http://localhost:8088/`.
